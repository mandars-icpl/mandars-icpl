# Mandar Sanghavi

Security platform engineer at [Infopercept](https://github.com/Infopercept), Ahmedabad. Work on Invinsense — XDR/SIEM/IAM.

> "Don't explain your philosophy. Embody it."
> — Epictetus

Most of what I build is backend and systems infra: Go services behind Cloudflare Workers/D1/Queues, identity and four-eyes approval systems, security telemetry pipelines. Primary contributor to the platform's SCIM/OIDC identity middleware (multi-tenant provisioning across Keycloak, Google Workspace, Entra ID) and its Go-based security data layer (storage, workers, EDR/SIEM connectors), and authored the tenant-isolation architecture standard it runs on. It lives in private company repos, so public contribution graphs undercount the work — this page leans on side-projects instead.

Primary stack: Go, C#/.NET, TypeScript (Next.js/React), Rust, Python, PostgreSQL.
