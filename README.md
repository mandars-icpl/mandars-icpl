## 🚀 About Me

I build backend and systems software for **Invinsense**, a unified XDR/SIEM/IAM security platform — service-to-service infra, identity and access systems, and the agents/pipelines that feed security telemetry. Most of my day-to-day work lives in private company repos (Go services behind Cloudflare Workers, D1, Queues; identity and four-eyes approval systems; SIEM/EDR agents), so this profile leans on public side-projects and OSS exploration to show the skill set.

I enjoy work that sits at the boundary of **performance and security**: low-level systems code, observability/tracing, and infrastructure that has to be correct under adversarial conditions.

- 🔭 Currently building: Go microservices + identity/approval systems for a multi-tenant security platform
- 🌱 Deepening: Rust for systems/security tooling, Cloudflare Workers + D1 edge architectures
- 🛡️ Domain: XDR, SIEM, IAM/identity, endpoint telemetry
- 💬 Ask me about: Go backends, Windows ETW tracing, OpenSearch, secrets management (Vault), .NET interop
